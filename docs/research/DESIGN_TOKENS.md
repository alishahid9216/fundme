# GoFundMe Design Tokens & Theme Specification

Extracted from live target: `https://www.gofundme.com/`

## 1. Color Palette

### Brand & Primary Colors
- **Brand Deep Forest Green**: `#024731` / `#005e3a` (Primary CTA, logo, active highlights)
- **Brand Deep Forest Green Hover**: `#003823` / `#004a2e`
- **Brand Dark (Trust & Safety Section)**: `#00321f`
- **Brand Soft Green (Hero Background)**: `#f6f9f8` / `#f0f7f4`
- **Brand Sage Green (Video Banner)**: `#b8e2c0` / `#9ddba9`
- **Brand Mint Highlight / Pill Badge**: `#e6f4ea` / text `#005e3a`

### Accent Colors
- **Warm Honey Yellow (CTA Section)**: `#fbedb6` / `#fdedc5`
- **Yellow Section Heading / Text**: `#2b1f09`
- **Badge Purple ("New")**: Background `#f3e8ff`, text `#7e22ce`
- **Badge Urgent ("Urgent")**: Background `#fee2e2`, text `#b91c1c` or `#9333ea`
- **Notification Red**: `#dc2626`

### Neutrals & Text
- **Foreground Primary Text**: `#1a202c` / `#1d2c22`
- **Foreground Secondary / Muted**: `#4b5563` / `#6b7280`
- **Border / Divider Color**: `#e5e7eb` / `#e2e8f0`
- **Card Background**: `#ffffff`
- **Footer Background**: `#f9fafb` / `#ffffff`

## 2. Typography

- **Font Family**: `"Geomanist", system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Hero Display H1**: `font-size: 3.75rem (60px)`, `font-weight: 800`, `line-height: 1.08`, `letter-spacing: -0.025em`
- **Section Heading H2**: `font-size: 2.25rem (36px)`, `font-weight: 700`, `line-height: 1.15`, `letter-spacing: -0.02em`
- **Card Title H3**: `font-size: 1.125rem (18px)`, `font-weight: 700`, `line-height: 1.3`
- **Body Regular**: `font-size: 1rem (16px)`, `font-weight: 400`, `line-height: 1.6`
- **Caption / Meta**: `font-size: 0.875rem (14px)`, `font-weight: 500`
- **CTA Button**: `font-size: 1rem (16px)`, `font-weight: 600`

## 3. Spacing & Grid System

- **Page Container Max Width**: `1280px` (`max-w-7xl`)
- **Header Height**: `80px`
- **Section Vertical Padding**: `80px` to `112px` (`py-20` to `py-28`)
- **Card Grid Gap**: `24px` (`gap-6`)
- **Card Padding**: `20px` to `24px`

## 4. Border Radius Scale

- **Pill Buttons & Badges**: `9999px` (`rounded-full`)
- **Featured Cards**: `16px` (`rounded-2xl`)
- **Hero Arch Cards**: `20px` (`rounded-3xl`)
- **Image Rounded Corners**: `12px` to `16px` (`rounded-xl` / `rounded-2xl`)

## 5. Shadows & Elevation

- **Scrolled Header Shadow**: `0 2px 8px rgba(0, 0, 0, 0.06)`
- **Card Default Shadow**: `0 2px 12px rgba(0, 0, 0, 0.04)`
- **Card Hover Shadow**: `0 12px 28px rgba(0, 0, 0, 0.12)`
- **Hero Arch Card Elevation**: `0 16px 36px rgba(0, 0, 0, 0.15)`
